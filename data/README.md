# Data

**The data are not included in this repository. They are available upon request
from the corresponding author, Ian J. Wallace (iwallace@unm.edu).**

The analytical data are individual-level records from the Orang Asli, an
Indigenous population of Peninsular Malaysia. Access is governed by the Orang
Asli Health and Lifeways Project (OA HeLP) and the associated ethics approvals,
so the files are shared on request rather than distributed publicly.

`data/processed/` is kept as an empty directory so the pipeline has the location
it expects. Once you have obtained the data, place the two CSVs described below
into `data/processed/` and the pipeline (see the top-level `README.md`) will
reproduce every fitted model, figure, and table.

**Without the data, `just example` writes synthetic files with these same names
and runs the pipeline on them.** They are generated by
`code/_experiments/make-example-data.R` from distributions stated in that
script; nothing in them derives from the real participants, and the results are
not the study's. See the top-level `README.md`. Because they take the real
files' names, check what is in `data/processed/` before reporting any number:
a synthetic file and a real one are told apart only by which command last wrote
them.

## Expected files

### `data/processed/orang-asli-pa-bone-data.csv`

The main analytical dataset (n = 1,007). Column names are snake-cased at load
(`janitor::clean_names`). The analysis code reads, among others:

| Column | Role |
|---|---|
| `age_years`, `sex`, `village_id` | age (tensor smooth), sex, community identity |
| `tibia_sos` | tibial speed-of-sound outcome (m/s; rescaled `/200` internally) |
| `ctx1_ng_ml` | CTX-1 resorption biomarker (ng/mL; modelled unscaled) |
| `osteocalcin_pg_ml` | osteocalcin formation biomarker (pg/mL; rescaled `/10,000`) |
| `ad_tot_step_count_0_24hr` | daily step count (rescaled `/5,000`) |
| `ad_mean_enmo_mg_0_24hr` | mean daily ENMO (mg; rescaled `/10`) |
| `industrial_index` | community-level industrialization index (industrialization exposure) |
| `functional_status_n_y_0_1`, `pregnant_or_breastfeeding_n_y_0_1`, `smoking_binary_n_y_0_1`, `alcohol_binary_n_y_0_1` | adjustment-set covariates |
| `fat_mass_kg`, `fat_free_mass_kg` | body composition (z-scored; confounder-DAG sensitivity specs) |

Daily step count and mean daily ENMO each appear twice: as the exposure in the
physical-activity → bone analyses, and as the outcome in the industrialization
analyses. Each variable carries exactly one rescaling, used in both roles. The
divisors for the two activity variables are also the reported contrasts (5,000
steps, 10 mg), so a slope per modelled unit is already a slope per reported
contrast. The rescaling itself is defined in one place, `prep_dat()` in
`code/_startup/functions.R`, and its rationale is in `code/_startup/data.R`.

`village_id` identifies the participant's community, and is the only place the
word "village" survives: the column keeps the name it has in the data file, and
the object names and output paths derived from it follow. Everything written for
a reader — prose, comments, figure labels, the manuscript — says "community"
instead, because several of the sampled settlements are sizeable peri-urban
areas rather than villages, so "community" is the more accurate word for the
unit. The two refer to the same thing. The column is deliberately not renamed,
so that the code matches the file you receive rather than a file you would have
to edit first.

### `data/processed/walking-experiment-data.csv`

The acute walking-experiment dataset (n = 10; pre / t0 / t4 osteocalcin
measurements), used only by `code/_experiments/walking-experiment-rope.R` for
the supplementary reverse-ROPE analysis. Three columns are read:

| Column | Role |
|---|---|
| `participant_id` | person identifier; the model's grouping term |
| `time_point` | `pre`, `t0` (immediately post) or `t4` (4 h post) |
| `osteocalcin_ng_ml` | osteocalcin (ng/mL) |

Age and sex are constant within person over the few hours the protocol spans,
so the participant term absorbs them and neither is read.

**Both filenames above are what the code expects.** They are generic on purpose:
whatever the files are called when you receive them, rename them to these, or
edit the two paths in `code/_startup/data.R` and
`code/_experiments/walking-experiment-rope.R` (and the `data_file` target in
`_targets.R`).
